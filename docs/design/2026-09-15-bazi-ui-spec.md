## 2. 逐段详规

### Ⅰ 工具说明 · 安静的底噪

- **目的**：三步之内让用户明白「这页做什么、不做什么」。不抢注意力，但「不能回答」必须同样可读。
- **示意要点**：定位句「按出生日期，排出年、月、日三柱」＋「可追溯的传统规则探索，不是命运测评」；两个清单（能回答：公历农历对照／年柱·月柱·日柱／天干地支基础五行／日干（日主）；不能回答：时柱·大运·流年／神煞·日主强弱／喜用神·忌神·评分／性格与现实预测）；「内部验证中 · 暂不公开」。
- **层级**：页面最轻层，标题与正文同段，不与 Ⅱ 段竞争。
- **间距**：段内 16px；段底 48px，与 Ⅱ 段拉开呼吸。
- **字号**：定位句 `text-base`（display 体）；说明正文 `text-sm`；清单 `text-sm`。
- **颜色**：定位句 `ink.dark`；正文 `ink.medium`；**「不能回答」仍用 `ink.medium`，不得降到 `ink.light`**。
- **组件**：`section-header`、`card-warm`（两个能力清单）、`divider-ink`。

### Ⅱ 本次操作 · 一张清晰的案头

- **目的**：所有输入一次看全；**禁用状态必须把「为什么不能点」写在按钮旁边**，而不是只把按钮变灰。
- **示意要点**：历法（公历／我只知道农历）；年月日（`1990 / 06 / 15`）；所选历法用于确定输入口径，换算结果在结果区单列、不覆盖填写内容；闰月仅农历时出现（是／否／未确认）；十四周岁勾选（未勾选时按钮不可用并就地说明原因）；「生成三柱」；「从本人档案带入」（冲突时就地显示「当前值 → 拟带入值」的替换确认，可撤销；草稿为空时直接带入）。
- **层级**：卡片承载，但弱于 Ⅲ 段；三个输入一行主序，说明文字退为辅助。
- **间距**：卡内 24px；字段组之间 16px；按钮组上距 24px。
- **字号**：字段值 `text-base`（等宽数字）；标签 `text-xs`；说明 `text-xs` 且**不低于 `ink.medium`**。
- **颜色**：生成键 `--seal`（**本屏唯一朱砂**）；带入入口为 ghost，不上色；禁用仅降 opacity + 文字原因。
- **组件**：`card-paper-solid`、`input-ink`、`btn-seal`、`btn-ghost`。

### Ⅲ 核心结果摘要 · 全页唯一的揭晓瞬间

- **目的**：这段最容易被做「空」。用最大字号、最宽留白、最稳的对齐让六个字有分量；**状态横幅必须排在三柱之前**。
- **示意要点**：状态横幅「✓ 已生成日期级结果：三柱（年、月、日）／共四柱，缺时柱」；三柱（年柱 庚午 金·火；月柱 壬午 水·火；日柱 辛亥 金·水，带日干标注）；限制与缺失收束（未生成时柱，因此不判断日主强弱、不给用神结论）。
- **层级**：状态横幅（第一眼）→ 三柱（唯一重心）→ 限制与缺失（收束）；DOM 顺序同上，不可倒置。
- **间距**：段顶 64px；状态到三柱 24px；三柱之间 12px；段底 64px。
- **字号**：柱字 `font-display` 约 2.4rem（移动端 1.9rem）；柱名 `text-xs`；五行 `text-xs`。
- **颜色**：干支按 `WUXING_COLORS` 上色，**同时**以文字写出五行名（不得仅靠颜色）；日柱额外用 `ink.dark` 描边 + 极浅洗底区分。
- **组件**：`BaziStatusBanner` + **新增三柱一览容器**（复用 `card-paper-solid` 与 `seal-icon`）。

### Ⅳ 通俗解释与详细结果 · 把六个字讲清楚

- **目的**：承接揭晓、逐项解释。候选对比必须给出**两个完整情形**且不只靠颜色；日期对照必须分清「你填写的」与「依规则换算的」。
- **示意要点**：
  - 三柱卡片：年柱 庚午（天干庚金 · 地支午火）／月柱 壬午（壬水 · 午火）／日柱 辛亥（日干辛金，即日主 · 地支亥水）。
  - 候选逐项对比（仅跨节时）：**情形甲 · 交节前**（年柱 庚午 · 月柱 辛巳 · 日柱 辛亥）／**情形乙 · 交节后**（年柱 庚午 · 月柱 壬午 · 日柱 辛亥）；两情形各用文字标注「甲／乙」，不只靠颜色；日柱在两情形中相同，故仍唯一。
  - 日期对照：你填写的＝公历 1990 年 6 月 15 日；依规则换算的＝农历 庚午年 五月廿三。
  - 怎样看懂这张盘：六问 · 三层折叠（原生 `details`：第一层问题 → 第二层解释 → 第三层依据）；展开区**不使用固定 max-height**。
  - 五行构成：六个字的**字面次数统计**，必须写明不代表旺衰、强弱、平衡与否，也不用于任何喜忌判断。
- **层级**：三柱卡片与 Ⅲ 段呼应但降一档；候选对比仅在 candidate 态出现且排在卡片之后。
- **间距**：子块之间 32px；卡片内 16px；折叠面板每层左缩进 16px。
- **字号**：卡片柱字 `font-display` 1.5rem；解释 `text-sm`；「你填写的／换算的」标签 `text-xs`。
- **颜色**：两个候选轨道用极浅洗底 + 细线框，**不用红绿**；日主用 `seal-icon` 小印标注，**不使用左色条卡片**。
- **组件**：`BaziPillarCard`、`BaziCandidatePanel`、`BaziDateComparison`、`BaziReadingGuide`、`BaziElementComposition`。

### Ⅴ 依据与范围 · 把「我们凭什么」摊开

- **目的**：用最低对比、最高密度承载可追溯性。措辞必须停在「古籍在线整理本」层级，不得越线。
- **示意要点**：来源清单（带等级，例如「农历换算：历法换算库；等级：古籍在线整理本；未完成原刻影印核对」）；版本（规则版本 + 换算库 1.7.7）；限制说明（年柱以立春为界是本项目采用的传统规则；支持范围自 1901-01-01 起；时区按 Asia/Shanghai）；未输出清单十四项；内容标签。
- **层级**：全页对比最低、密度最高；允许更小的字，但不允许不可读。
- **间距**：子块之间 24px；清单行高收紧至 1.6。
- **字号**：正文与清单 `text-sm` 下限；来源等级 `text-xs`；**不得低于 `text-xs`**。
- **颜色**：全部 `ink.medium`；等级标签用 `--gold` 描边 chip，**不填色块**。
- **组件**：`BaziEvidenceScope`、`divider-ink`；版本号取自常量，界面上以「中文名 + 版本」呈现，不展示内部标识串。

### Ⅵ 本次结果操作 · 保存与历史

- **目的**：保存是次级动作（不抢 Ⅱ 段生成键）；历史列表**只显示保存时间与概况，绝不显示出生日期**。
- **示意要点**：保存本次结果；「本次结果已保存 · 09-15 20:41」＋「重复保存不会产生第二条记录；保存失败时页面结果保留，可就地重试」；历史列表项「八字基础排盘 · 09-15 20:41 · 三柱（年/月/日）」，标注「不显示出生日期」「快照只读 · 可重算 · 可删除」；按条数清空（清空前显示将删除的条数）。
- **层级**：保存为次级实心键，不与 Ⅱ 段生成键同屏争主次；历史为可折叠区。
- **间距**：保存区与历史区之间 32px；列表项内 12px。
- **字号**：列表主行 `text-sm`；概况 `text-xs`。
- **颜色**：已保存用 `--jade` 描边 chip；清空确认用 `--cinnabar-dark` 描边 + 文字说明，**不使用整块红底**。
- **组件**：`BaziSaveDialog`、`BaziHistoryPanel`、`editorial-dialog-confirm`。

## 3. 状态矩阵

> 任务书 §5 全 13 态。**缺一态即不算完整稿。**

**四类状态横幅的语义（文字 + 图标 + 颜色三重编码）：**

| 图标 | 状态          | 横幅文案                                                     |
| ---- | ------------- | ------------------------------------------------------------ |
| ✓    | 成功 · 日期级 | 已生成日期级结果：三柱（年、月、日）／共四柱，缺时柱。       |
| ⋯    | 成功 · 跨节   | 该日期跨〈某节〉，年柱与月柱各有 2 种可能。                  |
| ↻    | 已过期        | 输入已修改，结果尚未更新；旧结果保留在页面上，保存入口禁用。 |
| !    | 失败          | 日期无效／超出范围／引擎未完成，三类各有独立原因文案。       |

**状态 → Ⅲ 段主区 → 主动作 → 安全出口。所有状态都不得清空已有输入。**

| 状态                      | 触发                | 用户看到                                                             | 主动作 / 安全出口             | 关键令牌                    |
| ------------------------- | ------------------- | -------------------------------------------------------------------- | ----------------------------- | --------------------------- |
| 初始                      | 进页                | 年月日全空、闰月未选、十四周岁未勾；生成禁用并写明原因               | 生成（禁用）／从档案带入      | `btn-seal` 禁用态降 opacity |
| 处理中                    | 点生成              | 生成中，输入保持可见可改                                             | 等待（可取消输入）            | 辅助文字色 + 微动效         |
| 成功 · 日期级             | 引擎返回 partial    | 「已生成日期级结果：三柱／共四柱，缺时柱」＋三柱卡片                 | 保存本次结果                  | `--jade` 状态色             |
| 成功 · 跨节               | 日期跨节            | 「年柱与月柱各有 2 种可能」＋恰好两个完整情形并列，日柱仍唯一        | 对照后择一理解                | `--gold` 状态色             |
| 已过期                    | 结果生成后又改输入  | 「输入已修改，结果尚未更新」＋旧输入摘要；旧结果保留                 | 重新生成；保存入口禁用        | `--gold` + 禁用 opacity     |
| 失败 · 日期无效           | 非法日期            | 「日期无效：〈原因〉」；输入保留，可就地修正                         | 修正后重试                    | `--cinnabar-dark`           |
| 失败 · 超出范围           | 早于 1901-01-01     | 「超出当前支持范围（1901-01-01 至今）」                              | 改日期                        | `--cinnabar-dark`           |
| 失败 · 引擎未完成         | 换算失败            | 「历法计算未完成，未生成任何默认结果」                               | 重试；**不回退默认值**        | `--cinnabar-dark`           |
| 保存失败                  | 保存请求失败        | 「本次结果仍未保存」＋可重试；**页面结果不消失**                     | 重试保存                      | `--cinnabar-dark` 描边      |
| 已保存                    | 保存成功            | 「本次结果已保存（时间），重复保存不会产生第二条记录」               | 查看历史                      | `--jade` chip               |
| 历史空态                  | 无记录              | 为空说明，不催促保存                                                 | —                             | 辅助文字色                  |
| 历史 · 列表/快照/清空确认 | 有记录／点清空      | 列表只显示保存时间与概况，**不显示出生日期**；清空确认显示将删除条数 | 快照只读 · 重算 · 删除 · 清空 | `editorial-dialog-confirm`  |
| 档案带入                  | 点带入              | 空草稿直接带入；有冲突时替换确认（显示当前值与拟带入值）→ 可撤销     | 确认 / 撤销                   | `btn-ghost` + 内联确认      |
| 边界提示                  | 交节距午夜 < 5 分钟 | 「该边界迫近日界，判定对精度敏感」                                   | —（只提示，不阻断）           | `--gold` 描边提示条         |

## 4. 响应式与可访问性

> 320 / 360 / 390 / 414 无页面级横向滚动；**320px + 200% 文本缩放不得回退**。

| 断点          | Ⅱ 输入                         | Ⅲ 三柱                       | Ⅳ 候选 / 对照                  | Ⅴ / Ⅵ              |
| ------------- | ------------------------------ | ---------------------------- | ------------------------------ | ------------------ |
| 桌面 ≥ 1024   | 单卡，年/月/日同行             | 三柱横排，柱字最大           | 候选双轨并列                   | 两栏阅读宽         |
| 平板 768–1023 | 单卡，同行                     | 三柱横排，柱字降一档         | 候选双轨并列                   | 单栏               |
| 手机 390–767  | 年/月/日换行，仍可一次看全     | 三柱横排，柱字 1.9rem        | 候选上下堆叠，标「甲 / 乙」    | 单栏，列表行距收紧 |
| 窄屏 320–389  | 字段纵排；日期对照仅组件内滚动 | 三柱纵排或压缩横排（保可读） | 候选堆叠，加滑动提示           | 单栏；字号不破下限 |
| 320px + 200%  | 控件仍可达，标签不裁切         | 柱字随 rem 放大，不溢出容器  | 允许组件内滚动并给等价文字摘要 | 正文仍可读         |

**可访问性硬要求**

- 触控目标 ≥ 44px；`focus-visible` 用 2px 朱砂描边，offset 2px。
- 弹层：初始焦点进入、Escape 关闭、Tab 不进入背景、关闭后焦点返回触发按钮、≤480px 近全屏。
- 自定义 radio / checkbox：`sr-only` input + 样式化 span，焦点环用 `.sr-only:focus-visible + span`。
- 每页唯一 `h1`；每个输入有可见 `label`；必填与错误不只靠颜色。
- 展开/收起适配 `prefers-reduced-motion`。
- 高密度内容只做**组件内**横向滚动，并给滑动提示（`scroll-hint-x`）与等价文字摘要。

## 5. 令牌与类

### 颜色令牌（用名称，不用任意色值）

| 用途                  | 令牌                                                                                                          |
| --------------------- | ------------------------------------------------------------------------------------------------------------- |
| 页面底 / 卡片面       | `--paper-lightest` / `--paper-light` / `card-paper-solid`                                                     |
| 主文字 / 正文 / 辅助  | `ink.dark` / `ink.medium`（正文下限）/ 辅助不低于 `text-xs`                                                   |
| 细线 / 分隔           | `--ink-faint`、`divider-ink`                                                                                  |
| 唯一强调              | `--seal`（生成键与印记，每屏 ≤ 2 次）                                                                         |
| 状态 · 成功           | `--jade`                                                                                                      |
| 状态 · 候选/过期/边界 | `--gold`                                                                                                      |
| 状态 · 失败           | `--cinnabar-dark`                                                                                             |
| 五行（数据编码）      | `WUXING_COLORS`：木 `--wood` · 火 `--fire` · 土 `--earth` · 金 `--metal` · 水 `--water`，回退 `--wx-fallback` |

**透明度一律 `color-mix(in srgb, var(--color-x) N%, transparent)`；禁止 `rgba()` 与 `bg-x/10` 斜杠写法。**

### 字体令牌

| 用途                     | 令牌                 | 下限      |
