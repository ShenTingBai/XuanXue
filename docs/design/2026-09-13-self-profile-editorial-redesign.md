- 不改：全站顶栏与移动抽屉（`layouts/default.vue`）、全站页脚（原型页脚本次有意不实现，见 §10）、数据层与 API、公开围栏。

## 6. 状态与交互

- **三态**：未录入 / 已录入 / 日期已删除（档案保留）。状态决定 Ⅰ 节内容与 Ⅳ 节是否显示"没有可删除的档案"。
- **编辑器**：由「修改出生日期」/「录入出生日期」/「重新填写出生日期」展开，默认收起；展开后焦点进入第一个字段；取消收起并清空草稿（沿用现有语义）。
- **差异确认**：仍由 `SelfProfileSaveDialog` 承担（新增/修改/无变化、409 冲突 + 重新读取、长期保存告知勾选）。
- **停止/重新允许带入**：状态行按钮 + 现有确认弹层；重新允许需勾选当前告知版本。
- **危险区**：默认折叠；展开后逐条显示操作与说明；删除确认仍走弹层。

## 8. 可访问性

- 卷目为 `<nav aria-label="档案卷目">` + 锚点链接，配合已有 skip link；点击后焦点落到目标节标题（`tabindex="-1"`）。
- 全站 `scroll-behavior` 与 `prefers-reduced-motion` 均已存在，锚点跳转需尊重 reduced-motion。
- 危险区：`aria-expanded` / `aria-controls`，键盘 Enter/Space 可展开，图标 `aria-hidden`。
- 用途矩阵：`<caption class="sr-only">`；窄屏转卡片式时用 `data-label` 保留列名语义。
- 状态胶囊不只是颜色：文本 + 状态点 `aria-hidden` 组合。
- 所有交互元素保持可见焦点环（沿用全局 `:focus-visible`）。

## 12. 风险与回滚

| 风险                                      | 缓解                                                                                   |
| ----------------------------------------- | -------------------------------------------------------------------------------------- |
| 大改模板触碰既有 DOM 断言                 | 先跑基线，逐项按新结构更新断言，不改断言语义                                           |
| 反向农历换算边界（1900/1901、闰月）       | 复用 `utils/self-profile/birth-date.ts` 既有依赖与范围校验；失败回退到公历字面，不抛错 |
| 卷目客户端高亮监听在 SSR/卸载泄漏 | `onMounted` 注册滚动/窗口/几何监听 + `onBeforeUnmount` 清理；SSR 阶段不访问 DOM                          |
| 危险区默认折叠降低可发现性                | 卷目直接给出「Ⅳ 归 · 归档与删除」锚点，且节内按钮文案明确                              |
| 视觉改版引入新全局类导致文档漂移          | 同步更新 `design-system.md`，并由现有测试/审查复核                                     |

**回滚**：本次改动为纯前端展示层，回滚即还原上述文件；不涉及数据库、API 与数据迁移。
