## 1. 口径与边界

1. **本台账只覆盖日期级三柱**（年柱、月柱、日柱）与农历对照。时柱、大运、流年、神煞、藏干、纳音、十神、强弱、喜用神**不在 R5 范围**（D1 裁决：严格按交付规范 §7.1 闭集）。
2. 时区与"今天"：**北京时间（UTC+8），Asia/Shanghai**（国标 §3.16/§3.17；治理规范 §8.2）。所有边界判定一律以北京时间的日历日与时刻为准。
3. **干支年界（正月初一）与八字年柱界（立春）不是同一条规则**，不得互相替代，也不得在 UI 里混用同一句解释（见 R-BZ-005）。
4. 所有纯日期计算以 `YYYY-MM-DD` 字符串承载，不经 UTC `Date` 中间转换（治理规范 §8.1）。
5. 每个规则登记 `sourceStatus`；`implementation_only` 的规则**不得**在用户可见界面被表述为历法事实或已核验传统规则。
