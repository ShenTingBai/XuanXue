## 1. 台账说明与口径约定

- 本稿只做**取证与定位**。它不表示候选引擎已符合国标，也不表示 R5 已通过任何验收。
- 计算口径：**北京时间（UTC+8），Asia/Shanghai**（国标 §3.16「东经 120° 标准时」、§3.17；治理规范 §8.2）。
- 支持范围：公历 1901-01-01 至 `asOfDate`（沿用 R3 下界，见 D9 裁决）。
- 干支年界与八字年柱界**必须区分**：国标 §6.1.1 的干支年按**农历年**（正月初一交替），八字年柱按**立春**（契约 §10.1，传统文化口径）。两者同为六十甲子序列，但切换日不同，**不得互相替代**（见 §3 GAP-BZ-001）。
- 黄金样例的期望值**不得**取自 `lunar-javascript` 或任何候选引擎输出（治理规范 §21.1、契约 §25.1）。本稿采用两类合法取得方式：
  1. **直接来源**：A 级来源直接给出的日期/时刻；
  2. **锚点算术**：由 A 级锚点加纯日期算术推出的值，逐例标注 `derivation`。
- 本轮工具限制（如实记录）：`web_search` 插件 endpoint 返回 HTTP 404 不可用；`web_fetch` 不支持 PDF。因此证据获取依靠已知稳定链接 + `web_fetch` + 本地下载后用 `pypdf` 与自写 PNG 解码**目视核对扫描页**。未安装任何新依赖。
