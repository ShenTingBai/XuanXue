## 6. 限制与未覆盖

1. **称骨 / 择日 / 星座三页在生产构建下不可达**：三者 `exposure: internal`，且称骨、星座 `computePolicy: blocked`、
   择日未获本次内部验证白名单授权，浏览器打开后由 `middleware/tool-availability.global.ts` 路由围栏
   重定向到 `/tools/status?tool=…`（Nuxt 客户端路由重定向，非 HTTP 302；直接请求该路径仍返回 200）。
   其文案层级**仅由源码断言与 `tool-copy-content.test.ts` 覆盖，未伪称浏览器已通过**。
2. **移动端截图未采集**：沿用既有环境限制（自动化后台标签页 rAF 节流导致截图超时）；
   §5 结论来自 DOM 文本与几何实测，非截图判读。
3. **副题中的既有预测口吻未改写**：称骨副题「解读一生命运走向」、择日副题「为你挑选最佳日期」、
   星座副题「今日运势…缘分匹配」属于内容真实性治理范围（计划 `must_not` 明确排除），
   不在本轮去重内，另行记录为 follow-up。
4. **称骨页仍保留输入区警示行与「注」面板的并存**：两者语义不同（即时输入口径 vs 算法溯源），
   不构成同一句重复，故保留。
5. **择日评分权重性质仍有两处可见落点**：「注」面板来源数据（完整解释）与「注」面板免责声明

   改它会影响使用该组件的 9 个工具页（cezi / constellation / guming / hehun / meihua / name-test /
   yijing / zeji / ziwei），超出本轮 allowed_paths，记为后续专项。
