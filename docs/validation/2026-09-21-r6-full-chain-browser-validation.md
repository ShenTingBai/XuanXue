| 21  | 同库双实例                   | 拒绝            | InstanceLockError         | PASS |

**关键结论**：

- 服务端不接受客户端提交的任意结果 JSON 作为可信历史（`digestsMatch` 不一致 → 409 不落库）；
- 非白名单账号即使登录也不能读/写八字历史（服务端白名单二次校验，客户端判定不是安全边界）；
- 认证/档案/历史响应全部 `no-store`，Service Worker 对 5 类敏感 API 注册 NetworkOnly 且先于通用 API 规则；
- 日志不记录出生资料、凭证、SESSION_SECRET 或原始会话令牌；
- 同一临时库双实例启动被实例锁拒绝（防 sql.js 整文件覆盖）。

  状态页显示「生肖 · 功能整理中 · 该功能正在依据与规则整理中，暂不提供新的计算结果」；
- **引擎边界**：`tests/utils/shengxiao-engine.test.ts`（14 例）与 `shengxiao-classification.test.ts`（6 例）
  覆盖 26 个日期黄金样例、农历新年前后、1901 下界、当天/次日边界、非法与范围外输入、60 条分类预期；
- **页面逻辑**：`tests/components/shengxiao-page.test.ts` 覆盖游客空草稿不自动计算、年龄门禁、
  修改后 stale 禁止导出/保存、卸载清除、公共文化切换不计算、档案带入/替换/撤销、无 localStorage 写入；
- **零服务器历史**：`/api/result-history?tool=shengxiao` 拒绝（shengxiao `historyPolicy=disabled`）；
- **禁止内容已退出生产路径**：`pages/tools/shengxiao.vue` 仅引用 `VerifiedResult`、`VerifiedCulture`、
  `BirthDateInput`、`ExportButton`、`ToolPageLayout`、`PageHero`、`SelfProfileSaveDialog`、`AuthDialog`，

  业务链路由上述自动化测试承担（与 R4 接受时「围栏下带入/替换/撤销由组件测试承担」先例一致）。
