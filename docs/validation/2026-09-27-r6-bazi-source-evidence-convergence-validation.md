## 3. 两个 GAP 的判定

### 3.1 GAP-BZ-001

官方资料清楚定义了节气和官方农历年界，但香港天文台资料同时明确把「立春换年」归为坊间命理主张；整理型八字文章则是在复述常见口径。当前证据最多支持以下限定表述：

> 本项目按八字传统口径，以立春交节作为年柱边界；该口径与官方农历正月初一年界不同。其传统规则的直接原文证据仍未完成核验。

不能写成「国家标准规定八字年柱以立春为界」或「古籍已经明确规定」。

### 3.2 GAP-BZ-007

本轮已取得国立台湾图书馆藏明万历六年刊本 `NCL-06589_1.pdf`，并定位到卷二目标篇章：`论四时节气` PDF 页 128–131、`论遁月时` PDF 页 143–144、`论年月日時` PDF 页 144–147。影像已目视核对当前限定主张；整卷逐字转录不属于本次关闭范围。OCR、网页转录和整理文章仍只能作为发现线索或二手证据。

另取得一份中国国家图书馆民国时期扫描 PDF：目录明确包含《论遁月时》和《论年月日時》，但版本为 1926 年秦慎安校勘本，不能替代明万历六年刊本。四库本录文中可定位“遁月从年”段落，但未检出直接把八字年柱切换系于立春的句子。

### 3.3 用户裁决

本轮未找到满足 `GAP-BZ-001` 直接原文要求的可靠原始/学术材料。用户已同意：找不到时停止开放式继续搜索，接受其余来源收敛与边界记录。该决定不把 `GAP-BZ-001` 标记为关闭；它仍是 R6 公开门禁阻断项。后续只有出现新的具名材料或另立计划时才重新复核。
