## 1. 本轮范围

只做内容层收敛：把 12 个工具页的「工具身份 / 事实 meta / 操作说明 / 本页边界」四类文案各归其位，
删除同一语义的跨层重复。**不改**布局结构、样式类、业务逻辑、计算、来源、工具目录、公开状态与服务端围栏；
不改变 `ToolEditorialShell` 的结构与 props。

## 2. 信息层级约定

| 层级                           | 职责                                              |
| ------------------------------ | ------------------------------------------------- |
| `edition` 眉题                 | 工具身份限定语（不再罗列会被别处重复的口径/清单） |
| `title` / `subtitle`           | 工具是什么（一行身份句）                          |
| `statusText` 状态胶囊          | 围栏/封存状态（保留，不按重复摘要删除）           |
| `metaText`                     | **短事实**：规则版本、引擎、依据、结果保存边界    |
| `indexFootnote` 卷目脚注       | 本页输入口径与计算/输出边界（不复述 meta 句）     |
| 正文 section note / 依据与范围 | 当前操作指导、完整边界清单                        |

**关键判断（本轮新增规则）**：`IndexNav` 的卷目脚注在 **≤920px 为 `display:none`**。
因此「结果只在本页内存 / 不保存」这类隐私与保存边界**必须留在 masthead 的 `metaText`**
（始终可见），不能只放在脚注里——否则去重会直接把边界从窄屏用户眼前拿掉。
涉及页面：cezi、hehun、ziwei、name-test、yijing、meihua（共 6 页据此把边界句从脚注移入 meta）。
