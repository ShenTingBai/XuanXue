## Status

Accepted。P1 只读真实性与移动端根因审计的结论与证据链已于 2026-09-01 经用户确认接受；本 ADR 记录该接受及随之作出的公开内容收缩决定。接受范围为审计证据与处置建议本身，不含任何未实施的产品变更。

## Context

- P0（提交 69c9479）已封存 ziwei、hehun、meihua 三个未审核工具的公开入口；本项目当前只做本地开发，产品定位是个人自我探索与公共文化体验，不是确定性预测。
- P1 对首页与 8 个 listed 工具页做了只读审计。经 P1 → P1.1 → P1.2 三轮修正（P1/P1.1 已 superseded，历史不可完全恢复的事实被如实保留），最终规范账本为 **190 个独立展示点**：分类 FR 84 / TC 49 / PCI 12 / UU 45；处置建议 retain 89 / relabel 91 / downgrade 9 / hide 1。
- 账本中的 `source_status` 没有任何 `verified` 条目：全部典籍、民俗与算法来源仍处于 unverified_reference 或 no_source 状态，来源核验从未完成。
- 移动端问题清单为代码证据推导，其中 MethodologyNote 组件的横向溢出与 Escape 失效已在真实浏览器复现（320/360/390/414 宽度下 cezi 页面级横向溢出 164/124/94/70px、name-test 320 下 151px、zeji 320 下 131px 等）；该复验在不提交任何表单、不写入用户数据的前提下完成，环境缩放上限实际为 3x，500% 缩放未测。
- 工具结果生成会触发既有自动保存（fire-and-forget），相关同意与保存治理尚未实施。

## Decision

1. **接受 P1 审计证据链**：以 P1.2 的 190 条规范账本、执行与审查历史说明、真实浏览器根因复验记录为 P1 阶段的正式证据；接受依据准确限定为独立账本复核、真实浏览器根因复验与用户接受三项，不多不少。
2. **删除全部工具页“注/算法溯源”UI**：用户决定遗弃该 UI，不以 CSS 修补、信息图标、抽屉、弹窗或未核验外链替代。MethodologyNote 组件随公开引用一并移除。
3. **P2 执行公开真实性收缩**：移除 P1 账本中 9 个 `downgrade` 公开工程评分展示、隐藏 `hide` 的生肖逐月运势 UI，并修正称骨（guming）默认输入补全缺口（五项出生信息完整且用户明确选择前不得计算）。
4. **来源注册表只在人工核验后讨论**：本 ADR 不建立任何来源注册表或方法/边界页面；后续若建立来源能力，只能在人工逐项核验后另行决策。

## Consequences

- P1 标记为 `Accepted`，P2（公开真实性收缩）可以启动；阶段与门槛以 `docs/project/stage-roadmap.md` 为单一事实来源。
- “注/算法溯源”UI 删除后，公开页面不再展示任何未核验典籍引注；这降低误导风险，但也意味着用户暂时失去页面内方法说明，来源能力的重建被推迟到人工核验之后。
- 9 个公开工程评分展示与生肖逐月运势被移除后，相关工具的结果区结构随之简化；内部计算引擎、常量与历史数据不删除，仅供既有确定性排序、历史兼容与后续审计。
- 自动保存、同意与历史保存治理不因本 ADR 改变，仍由后续阶段（P4）单独处理。

## Non-decisions

本 ADR 明确**不**代表以下事项已决定或已完成：

- 来源核验未完成：任何典籍、民俗或算法来源都未被人工对照核验，`verified` 来源为零；接受审计不提升任何来源状态。
- P2 产品实施未开始：本 ADR 只记录收缩决定，删除注 UI、评分展示与逐月运势 UI 的代码变更由 P2 计划执行并另行验收。
- 自动保存治理未实施：结果生成的 fire-and-forget 自动保存行为原样存在，留待 P4。
- 全站移动端验收未完成：除已复现的 MethodologyNote 根因外，其余移动端问题仍是代码证据推导，由 P6 移动端专项逐项验收；500% 缩放与真实移动端验证未做。
- 项目未发布：本文不表示项目可发布或已完成整体验收。
