# ADR-2026-09-04-002：确认公开试运行运行环境与文档边界

- 编号：ADR-2026-09-04-002
- 日期：2026-09-04
- 状态：Accepted

## Context

项目所有者已明确说明：XuanXue 已部署到可由互联网访问的服务器，主要用于本人日常使用和向他人展示，目前未主动宣传。

此前部分文档仍把当前阶段表述为“只做本地开发”或“项目未发布”。这些表述与当前客观可访问状态不一致，也容易让后续设计和验收忽略公网环境中的账号、接口、出生资料、历史记录和隐藏工具绕过风险。

与此同时，项目仍有多项工具未完成产品契约、来源核验、代码整改和公开验收。公网可访问不能被理解为产品已经完成或所有现有功能都获得公开批准。

## Decision

1. 当前运行环境统一分类为 `public_preview`，中文表达为“公开试运行”。
2. `public_preview` 只说明系统客观上可由互联网访问，不表示已经满足正式生产、安全、隐私、来源、内容或发布验收要求。
3. “未主动宣传”“主要供本人使用”不能把公网环境降格为本地环境，也不能降低服务端访问控制和个人信息保护要求。
4. 未通过公开准入门的工具必须同时控制首页、导航、SEO、PWA、直接路由、服务端接口、历史、最近使用、导出和示例；只隐藏入口不构成围栏完成。
5. 已批准产品规范继续作为目标合同；其 `Approved` 状态不表示代码已经实施。
6. 尚未形成契约的首页和其余工具继续标记为 `Pending`；已封存工具继续保持既有围栏，不因本 ADR 恢复。
7. 本轮只收口文档事实和规范关系，不修改产品代码，不生成实施计划。

## Relationship to ADR-2026-09-01-001

本 ADR 只替代 `ADR-2026-09-01-001` 中“当前只做本地开发”和“项目未发布”这两个已经过时的运行环境前提。

下列原决定不变：

- P1 审计证据的接受范围；
- 删除公开“注/算法溯源”UI；
- 收缩用户可见工程评分和生肖逐月运势；
- 来源核验没有完成；
- 自动保存、历史治理和全站移动端验收仍未实施。

旧 ADR 保留原文作为当时决策记录，不通过回写历史掩盖运行环境认识的变化。

## Consequences

- 产品文档首页、档案规范、通用工具规范和阶段路线图必须明确区分本地开发与公开试运行；
- 公开服务器上的现有可访问行为需要后续独立审计，不能由本次文档收口推定为安全；
- 涉及出生信息、账户、会话和历史记录的功能，在公网验收完成前不得宣称具备正式生产资格；
- 每个工具是否允许公开，继续由审核、访问、计算和历史四维状态共同决定；
- README 和项目展示材料必须区分“代码资产已经存在”与“功能已经批准公开”。

## Non-decisions

本 ADR 不决定或完成：

- 备案、应用商店上架、商业运营或正式发布；
- 云数据库、微服务、Spring Boot 后端或 AI 接入；
- 任何尚未讨论工具的产品规则；
- 公网安全整改方案或代码实施顺序；
- 来源核验、渗透测试、等保评估或专业法律意见；
- 现有用户数据的迁移、保留或删除操作。

## Evidence

- 项目所有者关于当前服务器公开可访问状态的明确说明；
- `docs/product/contracts/zeji-tool-contract.md` 第 19 章已采用相同的 `public_preview` 分类；
- `docs/archive/project-story.md` 记录了历史部署事实，但该文档只作为历史材料，不承担当前状态治理职责。
