## 2. 本次复核的三项

### 第 14 项：键盘和状态提示 — pass

v1 记录中该项虽判定 pass，但遗留 FU-002（tablist 无方向键/roving tabindex）。
本次已补齐并在生产构建上实测：

| 要求                          | 实测结果                                                    |
| ----------------------------- | ----------------------------------------------------------- |
| roving tabindex               | 任意时刻恰好 1 个 tab `tabindex=0`，其余 `-1`；Tab 只停一次   |
| ArrowRight/ArrowDown          | 选中下一项并移动焦点，末项回绕首项                            |
| ArrowLeft/ArrowUp             | 选中上一项并移动焦点，首项回绕末项                            |
| Home / End                    | 选中第一项 / 最后一项并移动焦点                               |
| 焦点与选中一致                | 键盘切换后 `document.activeElement` 为新选中 tab              |
| tab ↔ tabpanel 关联           | tab 有稳定 `id` + `aria-controls`；面板 `aria-labelledby` 跟随 |
| 鼠标 / Enter / Space 不回归   | 真实指针点击、Enter、Space 均正确选中并更新面板                |
| 状态提示非颜色唯一表达        | 失败 `role="alert"`、stale/处理中 `role="status"`，均带文字    |
| console 错误                  | 完整键盘遍历 + 点击过程中 0 条                                |

### 第 15 项：用户完成体验验收 — pass（工程层面），用户接受待确认

执行者已完成游客公开路径的真实浏览器复验（首页入口 → 生肖页 → 生成 → 键盘浏览），
并确认零服务器历史、输出闭集、四档与 200% 缩放、其他工具围栏均未回归。

**但执行者验收不替代用户本人的体验接受。** 该项在工程证据层面为 pass，
在产品批准层面仍待用户确认。

### 第 16 项：设计文档、代码和测试一致 — pass

v1 中该项因 FU-001（首页文案与公开事实矛盾）被标记为需 Codex 裁决。本次已收敛：

| 检查项                       | 结果                                                       |
| ---------------------------- | ---------------------------------------------------------- |
| 首页文案与目录事实一致       | 公开工具显示「已通过公开准入，可直接使用。」                |
| 文案工具无关（不硬编码生肖） | 公开分支不再拼接 `tool.name`，后续公开工具无需改此处         |
| 内部验证分支如实说明         | 「内部验证中（未公开）：点此进入。」                        |
| 目录 ↔ 页面 ↔ 围栏 ↔ SEO/PWA/sitemap | 全部由 `isToolPubliclyAvailable` 派生，一致            |
| 测试与实现一致               | 新增 10 项回归测试（index-content +3、shengxiao-page +7）    |
