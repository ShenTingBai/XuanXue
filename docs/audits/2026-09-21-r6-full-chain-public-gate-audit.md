>

## 3. 公开面审计（首页/导航/SEO/PWA/分享/历史）

### 3.1 无泄漏确认

| 面           | 结果                                                                                                 |
| ------------ | ---------------------------------------------------------------------------------------------------- |
| 首页         | 游客 SSR HTML 无任何工具名（生肖/八字/星座等 0 命中）；「术数工具」区只显示中性核验说明              |
| 顶栏导航     | 游客态只有「登录」；登录态账号菜单三项（账号与安全/本人档案/退出），无内部工具入口                   |
| sitemap.xml  | 仅 `/`、`/account`、`/login`、`/privacy`、`/terms`、`/tools/status`，**不含任何工具页**              |
| robots.txt   | `Disallow: /api/` ✓                                                                                  |
| PWA manifest | name/short_name/description 全中性，无工具名；start_url="/"                                          |
| SEO meta     | 首页 title/description/OG/Twitter 全中性（「传统文化自我探索」）；状态页中性                         |
| 状态页       | `getStatusOnlyToolFromQuery` 校验 query.tool；只显示「功能整理中」                                   |
| 分享         | 契约 §13.4 明确第一版不建设公开分享链接；无分享功能                                                  |
| 公开历史入口 | 首页无「最近记录/历史」；历史仅登录后八字页内部可见                                                  |
| 直接路由围栏 | 游客 `/tools/bazi` → 302 status（SSR）；`/tools/shengxiao` → 客户端重定向 status（SPA 壳+JS 重定向） |
| 软导航一致性 | 首页无工具卡片可点击；登录后白名单 A 可达八字页，非白名单 B 被 302 status                            |

### 3.2 发现的问题（非泄漏，但影响公开合规）

| #   | 问题                                   | 定位                                                                                     | 影响                                                                                                                                        |
| --- | -------------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **首页「命盘预览」示例含契约禁止内容** | `pages/index.vue` 的「命盘预览」区 + `constants/sample-bazi.ts`                          | 八字契约 §16 禁止的「日主：庚金（弱）」与「神煞：福星贵人 · 天生福气…衣食无忧」出现在公开首页；直接构成 bazi 公开门禁第 7、8、16 项 blocked |
| 2   | `robots.txt` 的 Sitemap 指向示例域名   | 构建产物 `robots.txt`（`xuanxue.example.com`）与 nuxt.config `siteUrl: xuanji.me` 不一致 | 配置一致性瑕疵；搜索引擎可能抓取错误 sitemap 地址；不泄漏内部工具，但公开启用前应修正                                                       |

## 4. 后续公开启用或返工计划的精确文件范围

以下为本审计**不实施**、但若推进公开必须纳入后续计划的文件范围（供 Codex 生成修正计划）：

- **bazi 公开前置返工（必须）**：
  - `constants/sample-bazi.ts`：移除/改写 `dayMasterStrength`、`favorableElements`、`unfavorableElements`、`elementPercentages` 等契约禁止字段；改写 `SAMPLE_SHENSHA` 的「天生福气…衣食无忧」描述为中性传统分类说明；
  - `pages/index.vue`：「命盘预览」区删除「（弱）」与神煞现实承诺措辞，或整体改为中性示例；
  - `nuxt.config.ts` / sitemap 配置：修正 robots.txt 的 Sitemap 域名与 `siteUrl` 一致；
  - 来源返工：关闭 `GAP-BZ-001`（立春年界原文）与 `GAP-BZ-007`（原刻影印核对）后重新审阅来源状态；
  - 公开体验验收：游客从首页进入八字页的完整公开路径（当前为 internal 围栏，无法验收）。
- **shengxiao 公开前置返工（若用户决定推进）**：
  - 单独裁决是否恢复 `computePolicy=enabled`（目录修改，需新计划）；
  - 公开体验验收（游客从首页进入生肖页）。

## 5. 计划遵守确认

- 本计划**未修改**任何目录、导航、SEO、PWA、API、页面或测试；
- 本计划**未**把 `public_preview` 运行环境等同于 `exposure=public`；
- 本计划**未**因 R5/R3 Accepted 自动批准任一工具公开；
- 浏览器通过**未替代**来源审阅（GAP-BZ-001/007 保持未决）；
- 本计划结论**不构成**用户最终批准或实际公开启用。
