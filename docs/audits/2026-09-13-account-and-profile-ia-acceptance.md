## 2. 顺带修掉的缺陷（本轮自查发现）

重做 `/self-profile` 时，页面自己 Teleport 的四个弹层（删除出生日期 / 删除整份档案 / 停止带入 / 重新允许）用的 `.auth-dialog-*` 原本是**各组件 scoped 定义**的，页面自身拿不到，等于弹层没有背板、面板与居中样式。本轮把 `.auth-dialog-*` 提升为 `main.css` 全局单一定义（同时统一 ≤480px 的按钮单列规则），并在真机验收中加入回归检查：弹层背景 `rgb(251,248,244)`、圆角 `16px`、外壳 `position: fixed`、面板宽度 384px。

## 5. 真机验收（32/32）

生产预览 + 系统临时目录全新库 + 独立随机 `SESSION_SECRET`，本机 Chromium：

- **落脚点**：注册后落在 `/self-profile`（空态「尚未录入出生资料」）；退出后访问档案页被送回 `/login`；重新登录仍落在 `/self-profile`；
- **账号与安全页**：顶栏账号菜单可进入；卷目四节锚点 `#sec-account/#sec-session/#sec-data/#sec-close` 齐全；展示昵称、`创建于 YYYY-MM-DD`、账号状态、真实隐私政策与服务规则版本 `2026-09-08`；档案状态摘要随真实摘要显示「已保存出生日期」；页面不含删除整份档案 / 删除出生日期；
- **弹层回归**：档案页删除弹层与账号页注销弹层均有背景、圆角与 `fixed` 外壳；
- **三类账号动作**：退出当前设备 → 回首页且原会话失效；重新登录后退出所有设备 → 回首页；重新登录后注销（昵称不一致被拒；昵称 + 密码正确后回首页且原账号无法再登录）；
- **响应式**：账号页 320/360/390/414 CSS px × 16px/32px 共 8 组无横向溢出；320px + 200% 注销弹层 `clientWidth 305 = scrollWidth 305`、可纵向滚动、确认按钮完整可见（x=16、宽 273、高 87）；
- **页脚统一**：档案页与账号页都渲染全站 `footer.page-footer`，含「玄·道」与「隐私政策」链接。
